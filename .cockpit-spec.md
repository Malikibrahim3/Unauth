# Unauth authenticated-app visual/product spec (Phase 4)

You are completing ONE page area of the Unauth authenticated app so it matches the
new dashboard cockpit. Read this whole file before editing.

## Product truth (non-negotiable)
- Unauth = **Shopify order/customer data + helpdesk claim history + evidence intelligence.**
- The CORE SETUP PAIR is **Shopify + helpdesk (Gorgias or Zendesk)**. Both are required.
  NEVER imply only Shopify is needed. NEVER make helpdesk feel optional when a page
  depends on claim/dispute context.
- **CSV is secondary historical import/backfill.** It must NOT be a primary CTA outside
  the upload/import/history pages. Inside those pages CSV-primary is fine.
- If useful merchant data exists, SHOW THE PRODUCT. Never hide customer/order/claim/
  evidence/watchlist data behind a first-run gate.
- "Empty" never means "no CSV audits." Existing Shopify/customer data means
  "started — finish setup," not "fresh."

## Canonical state services (Phase 2 — already exist, REUSE, do not rewrite)
- `getConnectionState(serviceClient, merchantId)` → `ConnectionState`
  ({ shopify, helpdesk, helpdeskProvider, bothConnected, neitherConnected,
  shopifyOnlyConnected, helpdeskOnlyConnected }) from `@/lib/connections/getConnectionState`.
- `getMerchantDataPresence(serviceClient, merchantId, userId)` → `MerchantDataPresence`
  (hasAnyData, hasCustomerProfiles, hasShopifySignals, hasHelpdeskClaims,
  hasEvidencePackages, hasWatchlist, hasCsvImports, sources:{customerProfiles,
  auditTransactions, shopifyOrderSignals, merchantClaims, supportCases,
  evidencePackages, watchlistEntries, ...}) from `@/lib/supabase/getMerchantDataPresence`.
- `resolveMerchantSetupState(connection, presence)` → MerchantSetupState; and
  `shouldFullGate(state)` from `@/lib/connections/getMerchantSetupState`.
- Pages already loading these should keep doing so. A full first-run gate is ONLY ever
  shown when `shouldFullGate(state)` is true (fresh / *_only_empty / fully_connected_empty).
  Filtered-zero (data exists, filters exclude all) must show "No X match filters", NOT onboarding.

## Visual system — use the EXISTING UI kit, do not invent a new one
Import from `@/components/ui`:
- `PageHeader` — every page gets a strong header: `title`, `subtitle`, optional `eyebrow`,
  `primaryAction`, `secondaryActions`, `tabs`. Primary action is an accent button;
  secondary actions are quiet/outline.
- `MetricCard` — KPI strip cards (label, value, hint, icon). Premium, not raw grey blocks.
- `SectionCard` — bordered content modules (title, description, actions).
- `EmptyState` — meaningful empty states (icon, title, description, action).
- `Tabs` — internal sub-navigation (e.g. Reports Overview / CSV audits / Live reports).
- `Badge` (tones: neutral, info, accent, success, warning, danger, critical),
  `ConfidenceBadge` (A–F), `ActionBar`, `DataTable`.

## Palette — Unauth maroon/rust/espresso/neutral ONLY
Use CSS tokens, never hardcoded off-brand hex:
- accent/CTA: `var(--accent)` (#7B2D26 rust) + `.btn-accent` class; hover `var(--accent-hover)`.
- text: `var(--ink-primary)`, `var(--ink-secondary)`, `var(--ink-tertiary)`,
  `var(--text)`, `var(--text-muted)`, `var(--text-subtle)`.
- surfaces: `var(--bg-surface)`, `var(--bg-surface-alt)`, `var(--surface-raised)`.
- borders: `var(--border-default)`, `var(--border-subtle)`, `var(--surface-border)`.
- status: `var(--sev-clear)` (green-ish, success), `var(--warning)` (amber, incomplete/setup),
  data: `var(--data-score)`, `var(--data-currency)`.
- BANNED in product UI: any `blue-*`, `sky-*`, `indigo-*` Tailwind classes; hardcoded
  `#2563EB`, `#1F73B7`, Google-blue Chrome pills; neon; gimmicky AI gradients.
  External brand LOGOS may keep their real brand colour (Shopify green #96BF48 etc.) —
  but product controls/pills must use Unauth tokens.

## CTA logic by connection state (apply wherever a "finish setup" CTA appears)
- shopify only → primary "Connect helpdesk"
- helpdesk only → primary "Connect Shopify"
- neither + no data → "Connect Shopify and your helpdesk"
- data exists + disconnected (stale) → "Reconnect sources"
- both connected → product action (e.g. "Review queue"), no setup CTA.
CSV always a quiet secondary ("Import CSV") outside import/history pages.
