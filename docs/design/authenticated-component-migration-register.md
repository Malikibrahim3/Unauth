## Why `components/claims/**` and `app/(app)/claims/**` are excluded

Git status at the start of this pass showed uncommitted, in-flight changes in `ClaimsQueueClient.tsx`, `claimReviewState.ts`, and related files — part of the separate "craft overhaul" effort described in `docs/IDE_PROMPT_authenticated_ui_craft_completion.md`. Every claims-review duplicate above is real and fully documented, but fixing it here would mean editing files mid-flight in someone else's active work, which risks clobbering it and conflating two unrelated efforts. It has an explicit owner (this table) rather than being silently dropped.

## What "internal token-alias swap only" means

For the primitives marked this way, the component's public API, className/style props, and rendered output are unchanged — only the internal `var(--radius-md)`/`var(--accent)`/etc. references were swapped for the new `--ua-*` names, which resolve to the exact same values (see `styles/authenticated/tokens.css`'s alias-forwarding mechanism). Zero visual change, zero caller-facing change. This is deliberately the least risky form of "migration" available and was chosen over rewriting call sites, per the brief's instruction to migrate only safe shared call sites without a risky full-app replacement.

**What was actually swapped, precisely:** radius (`--radius-sm/-md/-full` → `--ua-radius-control/-input/-card/-overlay/-pill`), shadow (`--shadow-md/-overlay/-modal/-drawer/-lg` → `--ua-shadow-card/-overlay/-modal/-drawer/-toast`), control dimensions (`--button-height-*`, `--input-height`, button padding-x → `--ua-control-height-*`/`--ua-control-padding-x-*`), z-index (`--z-modal/-drawer/-toast/-sticky` → `--ua-z-modal/-drawer/-toast/-header`), and the brand/accent colour (`--accent`, `--accent-hover`, `--accent-fg-on-500`, `--brand-deep`, `--brand-signal`, `--accent-border` → their `--ua-*` equivalents) plus `StatusBadge`'s four safe semantic tones (see above). Every one of these was verified as an exact-name forward with no light/dark divergence before swapping.

**What was deliberately NOT swapped, and why:** every `var(--space-N)` reference (N≥7) — `--ua-space-N` uses a Tailwind-style renumbering above 24px that does **not** match the existing sequential scale's own numerals one-for-one (e.g. `--ua-space-8` is `var(--space-7)`/32px, not `var(--space-8)`/40px — see the warning comment in `tokens.css`), so a same-numeral swap risks silently changing a real pixel value. `Badge.tsx`/`badgeStyles.ts` (see above). `StatusBadge`'s `danger` tone (see above). Any color reference without a verified exact-name `--ua-*` alias (e.g. `Card.tsx`'s `--border`/`--text-primary`/`--surface`/`--surface-hover` base colours were left as-is — only geometry and brand-accent got the alias treatment this pass).
