# Embedded font licences

The Chrome and Zendesk Pocket Briefs package Latin subsets of Inter and DM Mono
so their typography does not depend on host-installed fonts.

- Inter — Copyright 2016 The Inter Project Authors. Licensed under the SIL Open
  Font License 1.1: <https://github.com/rsms/inter/blob/master/LICENSE.txt>
- DM Mono — Copyright 2020 The DM Mono Project Authors. Licensed under the SIL
  Open Font License 1.1: <https://scripts.sil.org/OFL>

The files are the same subsets produced by the application's `next/font`
pipeline; no font outlines were modified.
